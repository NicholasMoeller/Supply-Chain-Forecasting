BEHAVIOR NOTES:
=========================================================================

1. Mode Selection:
   - Single Component: Shows txtColumnName, hides batch options
   - Batch Processing: Hides txtColumnName, shows batch options

2. Button States:
   - Load Data: Always enabled
   - Analyze: Enabled after data loaded
   - View Results: Enabled after analysis complete
   - Export: Enabled after analysis complete

3. Progress Updates:
   - Progress frame only visible in batch mode during processing
   - Progress bar updates for each component processed
   - Status label shows real-time component being processed

4. Quick Mode vs Full Diagnostics:
   - Quick Mode: Only metrics table, summary charts (fast)
   - Full Diagnostics: Detailed charts for top/bottom 10% (slower)
   - Mutually exclusive options

5. Color Coding:
   - Blue: Info/Ready
   - Green: Success
   - Orange: Processing
   - Red: Error
