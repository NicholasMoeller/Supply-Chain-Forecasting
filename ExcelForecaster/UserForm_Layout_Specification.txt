STEP-BY-STEP PLACEMENT:
═══════════════════════════════════════════════════════════════════════════

1. Open ForecastGUI in designer (double-click in VBA Project Explorer)
2. Open Toolbox (Ctrl+T) and Properties window (F4)
3. For each control above:
   a. Click control type in Toolbox
   b. Click on form to place it
   c. In Properties window, set Name property
   d. Set all other properties as specified
   e. Position using Left/Top values


ALTERNATIVE: QUICK LAYOUT METHOD
═══════════════════════════════════════════════════════════════════════════

If exact positioning is not critical, you can:

1. Add all controls in any position
2. Set their Name properties correctly
3. Use Format menu to arrange:
   - Select multiple controls (Ctrl+Click)
   - Format → Align → Lefts/Rights/Tops
   - Format → Vertical Spacing → Make Equal
   - Format → Horizontal Spacing → Make Equal

The code will work as long as the Name properties match!
